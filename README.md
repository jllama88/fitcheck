# FitCheck

Your closet, styled. A wardrobe inventory and outfit builder for the clothes you already own.

## Prototype

`index.html` is a single-file, no-build HTML prototype. Open it in a browser.

- **Studio**: an avatar in an arched fitting-room mirror wears the outfit (customise skin tone, hair and build; switch to Rack view for flat garments). It has one slot per category (outerwear, top, bottom, shoes, accessory). Cycle each slot with the arrows, lock pieces you want to keep, and hit **Style me** to fill the rest from your closet. A fit score explains colour harmony, vibe and weather fit.
- **Closet**: inventory with wears and cost per wear. Add items by photo (colour is read from the image as a stand-in for AI tagging) or by describing them (a stock illustration is matched).
- **Looks**: saved outfits grouped into sets (e.g. Work week, Weekend).
- **Brand**: logo, palette, type, motifs and voice.

The starting closet is sample data. Changes are saved in the browser's localStorage only.
